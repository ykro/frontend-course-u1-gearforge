# GearForge Studio

Configurador de workstations con catálogo de componentes, build con precio y consumo, panel de compatibilidad y formulario de cotización (React 19, Vite, TypeScript, Tailwind v4).

## Unidad 1

Plantilla de la Unidad 1 del curso.

## Requisitos

- Node.js 24 (versión en `.nvmrc`).

## Instalar y correr

```bash
npm ci
npm run dev
```

La app queda en http://localhost:5173.

## Tests

```bash
npm test             # solo los tests
npm run verify       # chequeo completo
```

El archivo `AGENTS.md` trae las reglas para el asistente de IA.

El enunciado del reto, la rúbrica y la guía paso a paso están en el curso.
